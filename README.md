# The AIRA's Journey（アイラの旅）

『アイラの旅』の小説版と3Dゲーム版を制作するプロジェクト。

## 原作設定

既存の世界観・人物・時系列の参照元は [my-memory の「アイラの旅」](https://github.com/tomiya7688/my-memory/tree/main/作品/アイラの旅)。
確定事項・暫定設定・競合する記録を区別し、新しい説明だけを自動的に正史にはしない。

## 3Dゲーム版

- **形式**：現時点ではシングルプレイヤーの3D RPG。原作世界の規模が非常に大きいことと、MMOとして多人数接続することは区別する。
- **グラフィック**：アニメ調。
- **選定方針**：開発速度・表現品質・実行時の軽さのバランス。原作の規模をエンジン都合で縮小する前提にはしない。
- **第一候補として採用**：Unity 6.3 LTS + URP + C#。実制作と性能検証を通じて判断を見直せる設計とする。

### 第1弾の制作範囲

**アイラの誕生から、神の世界・レスリア村で副村長を殺害し、村から逃げるところまで。**

これ以降の「素晴らしい世界」での生活や、後年の旅は第1弾には含めない。
前史の詳細や生贄制度の年齢設定には未確定・競合する記録があるため、決め打ちで創作しない。
