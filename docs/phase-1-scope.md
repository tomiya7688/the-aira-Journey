# 3Dゲーム版 第1弾の制作範囲

- **記録日**：2026-10-15
- **範囲指定**：作者の指示による
- **設定の参照先**：[my-memory / 作品 / アイラの旅](https://github.com/tomiya7688/my-memory/tree/main/作品/アイラの旅)
- **位置付け**：『アイラの旅』3Dゲーム版の最初のリリース単位。後続の世界・時代まで今回実装するという意味ではない。

## 第1弾の開始地点と終了地点

**開始：アイラが生まれるところ。**

**終了：神の世界・レスリア村でアイラが副村長を殺害し、村から逃げるところ。**

第1弾は「神の世界でのアイラの前史と、逃亡に至るまで」を扱う。**村からの逃亡後に訪れる世界は、第1弾の本編範囲へ含めない。** 具体的には「素晴らしい世界」の通行証制度、リーアス号による別世界への移動、物理の世界、悲しい世界、魔法世界の各国等を、この段階の必須実装範囲としない。

重要なのは、将来の全世界を縮小・省略すると決めたわけではなく、**第1弾の制作範囲を原作の冒頭に絞った**こと。

## 原典に矛盾・不足がある事項（現段階では確定しない）

### 生贄の年齢・選定時期

- **2025-12-21の前期説明**：村や街が毎年1月1日時点で満12歳の少女を選び、選定された少女の誕生日に生贄にする。
- **2026-07-03の再説明**：満10歳で選定、13歳の誕生日に生贄。アイラは13歳の誕生日前日に父親から逃亡を促される。
- **2026-10-11の本人確認**：前期説明を**暫定優先**。ただし正式確定ではない。

このため、ゲーム側で「10歳選定・12歳生贄」など第三の数字の組み合わせを作ったり、一方を勝手に確定設定として扱ったりしない。

### 逃亡・殺害の細部

- **2025-07-27の説明**には、副村長を含め計4人を殺したとする記録がある。
- **2025-12-23の記録**には、憲兵テテンの殺害に言及する資料がある。
- **2026-07-03の説明**では、両親を失うこと、副村長を撃ち殺すことが語られている。

各記録の具体的な事件順、殺害人数、使用武器、関係者の動機、両親の死亡時期・経緯等は、初期原典との照合が必要。**副村長殺害という第1弾の終点は固定するが、未確定な細部を補って正史として扱わない。**

### 誕生・幼少期の不足情報

ユーザー指定の開始点は「誕生」だが、現時点で参照した my-memory には、誕生の日時、出生場面の具体的な進行、家族の氏名、幼年期の出来事をすべて確定できるだけの情報はない。

ここは**制作上の未確定項目**として置く。プレイ可能な年齢、時間経過の見せ方、回想・イベント演出の使い方も後で決める。

## 制作フェーズのたたき台（新しい正史設定ではない）

以下はゲーム制作上の区切り案。出来事の正確な順序と描写を採用するときは原典を確認する。

1. **誕生と幼少期**：出生から村で暮らす時期を描く。操作可能な部分・映像演出の配分は未定。
2. **レスリア村の日常**：村人との関係、家族、生活や制度などの背景を示す。
3. **生贄の選定と葛藤**：選定制度が個人の生存と衝突する経過を扱う。年齢・告知の時期は未確定事項として保持。
4. **逃亡の局面**：副村長との対立・殺害、そしてレスリア村からの脱出で終える。

年齢ごとの自由行動、戦闘、選択肢や分岐、イベント順、NPC数、村の面積などは**現時点で仕様未決定**。設定が固まるまでゲーム的な都合で埋めない。

## 第1弾で重視する制作・技術面

- 神の世界の歴史・社会・宗教制度を、ゲーム画面に必要な範囲で再現する。
- 人物・村・家・道・自然・季節などのアニメ調3D表現の基準を確立する。
- 時間経過や物語イベントを更新しやすい、データ駆動のイベント制作基盤を作る。
- NPCが暮らしている感覚を描く手法を検討する。全世界のNPCシミュレーションを第1弾の必須要件とはしない。
- 村の描画負荷、NPCの処理、演出とロード時間、アセット制作・修正にかかる時間を計測する。
- 後続作品の舞台追加を妨げないよう、作品設定／ストーリーデータ／描画資産／ゲームロジックの責務を分ける。

エンジンの詳細は [ゲームエンジン選定記録](engine-selection.md) を参照。
